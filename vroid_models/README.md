# Meta-chan VRM

`meta_chan.vrm` is the project's mascot model, authored by Me. The frontend loads it by default; set `VITE_MASCOT_VRM_URL` to override it.

The model uses the [VRM Public License 1.0](https://vrm.dev/licenses/1.0/), with these settings embedded in the file:

- Avatar use is allowed for everyone for any kind of use
- Redistribution and modifications are allowed
- Optional: please credit Me when using or redistributing the model

These terms apply to the model only. The repository's MIT license applies to original code, not this asset.
