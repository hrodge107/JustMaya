# Meta-chan VRM

Meta-chan is Meet Mita’s mascot, created by the me under the alias Duhbinchi using VRoid Studio during the event duration. The frontend loads `meta_chan.vrm` by default; set `VITE_MASCOT_VRM_URL` to use another model.
