# Meta-chan VRM

`meta_chan.vrm` is the project's mascot model, authored by Duhbinchi. The frontend loads it by default; set `VITE_MASCOT_VRM_URL` to override it.

The model uses the [VRM Public License 1.0](https://vrm.dev/licenses/1.0/), with these settings embedded in the file:
